# Mock API samples

Sample responses matching the contracts in [../auth.md](../auth.md) and
[../orders.md](../orders.md), for building UI before the endpoints exist
(S1-05, S1-09). All people, phone numbers and addresses are fictional, and every
record is marked `is_simulated: true` where the field exists.

There are no prices: Sprint 1 orders are quote requests (see
[../orders.md](../orders.md#why-sprint-1-orders-have-no-price)).

If a contract changes, update these files in the same PR.
